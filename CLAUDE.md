# wellington-reboucas

Opere site institucional em arquivo único, sem framework e sem build.

## Comandos reais

1. Sirva local com: `python -m http.server 8000`.
2. Publique em GitHub Pages pelo workflow .github/workflows/pages.yml.
3. Use as alternativas do README.md só quando pedido: Cloudflare Pages, Vercel, Netlify Drop.

## Estrutura

1. Edite index.html como fonte única, guarde mídia em assets/.
2. Leia README.md antes de trocar foto, WhatsApp ou datas de 2026.
3. Não copie foto do Instagram sem autorização, use placeholder até receber original.

## Limites

1. Não crie build, teste ou lógica de negócio.
2. Não invente comando npm, eles não existem no repo.
3. Não commite, não faça push, não crie branch sem pedido.

## Débitos explícitos

1. Sem package.json, sem testes automatizados.
2. Sem lint configurado, valide com revisão manual.
